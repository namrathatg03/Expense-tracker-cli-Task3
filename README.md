# 💰 Expense Tracker CLI (Task 3)

This is a Python-based Expense Tracker built as part of my Python Internship Task-3.

## 🚀 Features

* Add expenses with category
* View all expenses
* Search expenses by category
* Calculate total spending per category
* Calculate monthly spending

## 🛠 Technologies Used

* Python
* CSV file handling

## ▶️ How to Run

1. Clone this repository
2. Run the file:

   ```bash
   python expense_tracker.py
   ```

## 📂 File Structure

* expense_tracker.py → Main program
* expenses.csv → Stores expense data

## 📌 Example Categories

* Food
* Travel
* Shopping
* Bills

## 🎯 Purpose

This project demonstrates data handling, filtering, and calculations using Python.
